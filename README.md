# PINAPPLE

A student portal frontend prototype built with React and Vite.

## Stack
- React + Vite
- Plain CSS
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Render
Create a **Static Site** connected to this GitHub repository:
- Build command: `npm install && npm run build`
- Publish directory: `dist`

## Current prototype scope
- Responsive student portal UI
- Games, social, media and study catalogues
- Google Classroom shortcut: https://classroom.google.com/h/st
- Sign-in form layout (client-side preview only)
- Messaging and admin analytics preview screens

**Important:** Authentication is not implemented. The sign-in form does not verify accounts or send credentials to a server. Messaging is local-only and admin statistics are placeholders. Do not enter real passwords or real student information. A backend, secure password hashing, role-based access control and privacy review are required before real student use.

Third-party services are opened through their official websites. This project does not proxy, mirror or bypass their access controls.
